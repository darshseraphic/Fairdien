03 / YOUR DATA

Your tasks stay
close to home.

Fairdien stores tasks and your appearance preference in chrome.storage.local within your Chrome profile. The current extension does not require an account, a remote task service, or access to the websites you visit.

Local extension storageNo accountNo host permissionsNo cloud task service

Fairdien does not add application-level encryption to task data. Avoid storing passwords or information that needs stronger protection. Anyone with access to your operating-system account or Chrome profile may be able to access local browser data.

02 / LOAD IN CHROMEDEVELOPER MODE
  1. 1 Open chrome://extensions.
  2. 2 Turn on Developer mode.
  3. 3 Select Load unpacked.
  4. 4 Choose the cloned Fairdien folder containing manifest.json.
  5. 5 Pin Fairdien from Chrome's Extensions menu for quick access.

When you update the source files, return to chrome://extensions and select Reload on the Fairdien extension card.

05 / QUICK ANSWERS

Good to know.

Does Fairdien need an account?

No. Tasks and appearance preference are stored locally in your Chrome profile. Fairdien does not require a separate account.

Where are my tasks stored?

Tasks are stored with chrome.storage.local in the Chrome profile where you installed and used the extension. Fairdien does not provide its own cloud task sync.

Can I set a reminder for a specific date?

The task form uses a time-only reminder picker. Fairdien schedules the next occurrence of the selected local time: later today if it is still ahead, or tomorrow if that time has already passed.

Will reminders work if Chrome is closed?

Reminder delivery depends on Chrome running and your operating system allowing Chrome notifications. Browser alarms and desktop notifications are not guaranteed alarms, so do not rely on them for safety-critical or time-critical activity.

Can I change or remove a reminder?

Yes. Edit the task to choose a different time, or use Clear time to remove its reminder. You can also complete, reopen, or delete tasks.

What can I do from a reminder notification?

Where supported by your operating system's notification interface, you can choose Mark done or Snooze 10 min. Selecting a notification opens Fairdien.

Is Fairdien available in the Chrome Web Store?

Not at this time. The current installation method is to clone the source repository and load the extension unpacked through Chrome's Developer mode.
